# 🚀 Automated UPI Transaction Bot

## 📌 Overview
A highly efficient and secure backend service built to automate and scrape UPI transaction details. Developed using **Python, FastAPI, and Playwright**, this bot automates browser interactions to fetch transaction data in real-time and serves it via fast RESTful API endpoints.

## 🛠️ Tech Stack
* **Backend Framework:** FastAPI (Python)
* **Automation & Scraping:** Playwright
* **Server:** Uvicorn

## ✨ Key Features
* **Automated Data Extraction:** Uses Playwright to securely navigate and extract transaction histories.
* **High Performance API:** Built with FastAPI for lightning-fast, asynchronous request handling.
* **Secure Execution:** Headless browser automation ensures secure and seamless background processing.
* **Easy Integration:** Clean REST API structure that can be easily integrated into any frontend or dashboard.
